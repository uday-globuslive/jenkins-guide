# Jenkins Practice Labs Workbook (Very Simple)

## Lab 1: First green build
- Create pipeline
- Add echo steps for Build and Test
- Run and make it green

## Lab 2: Learn failure
- Add one wrong command
- Run and see red
- Fix command and make green

## Lab 3: Credentials lab
- Save token in Jenkins Credentials
- Use token in pipeline
- Confirm token is not printed

## Lab 4: Agent lab
- Add two agents with labels
- Build on one, test on another

## Lab 5: Quality gate lab
- Make test fail
- Confirm deploy stage does not run

## Lab 6: Deploy lab
- Deploy to staging
- Run smoke test
- approve production

## Lab 7: Rollback lab
- simulate bad deploy
- rollback to old version
- verify service health

## Lab 8: JCasC lab
- change config yaml in git
- merge PR
- reload Jenkins config
- rollback with revert

If you finish all labs, you are ready for real projects.
